# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Chủ cần đánh giá issue này               |
| `needs-info`               | `needs-info`         | Chờ người báo bổ sung thông tin          |
| `ready-for-agent`          | `ready-for-agent`    | Đủ đặc tả, agent có thể làm AFK          |
| `ready-for-human`          | `ready-for-human`    | Cần người cài đặt                        |
| `wontfix`                  | `wontfix`            | Sẽ không làm                             |

Ngoài năm nhãn trạng thái, repo còn dùng hai nhãn **loại** đã có sẵn của GitHub:

| Nhãn loại | Dùng khi |
| --------- | -------- |
| `bug`     | Có cái gì đó hỏng                        |
| `enhancement` | Tính năng mới hoặc cải thiện          |

Mỗi issue đã qua triage mang đúng một nhãn trạng thái và một nhãn loại. Nếu hai nhãn trạng thái cùng tồn tại, báo chủ trước khi làm gì khác.

Nhãn riêng của repo: `no-docs` (refactor thuần hoặc chỉ sửa test, được CI `docs-required` bỏ qua), `wayfinder:map`, `wayfinder:task`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`.

Khi skill nói tới một vai trò (ví dụ "gắn nhãn AFK-ready"), dùng đúng chuỗi nhãn trong bảng trên.
