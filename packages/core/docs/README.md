# docs của packages/core

Tài liệu chính của thư viện đã chuyển lên site docs ở `docs/` (gốc repo), published tại <https://minhdevtry.github.io/ticket/>. Thư mục này chỉ giữ hai thứ nằm cạnh code:

- `adr/`: quyết định kiến trúc của riêng package (chỉ mục sinh tự động ở site: trang "Chỉ mục ADR").
- `parity/`: báo cáo do `scripts/shadow-parity.ts` sinh (ảnh chụp tại thời điểm chạy, xem trang "Chạy shadow").
