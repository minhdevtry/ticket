# docs của apps/tieulinh

Tài liệu dùng chung nằm ở site docs (`docs/` ở gốc repo). Thư mục này giữ phần gắn chặt với Tiểu Linh:

- `CONTEXT.md`: từ điển nghiệp vụ (tờ khai, nhánh, người báo, người xử lý...). Dùng đúng các từ này trong code và docs.
- `KG_CAUSE_TAXONOMY.md`: thiết kế tầng phân loại nguyên nhân của Knowledge Graph.
- `adr/`: quyết định kiến trúc của app.
